The [Logical Thinking Process skill](/skills) is now called `ltp`, while Reason Commons remains the project name. Install it with `npx skills add reasoncommons/reasoncommons -s ltp`; if you installed `reason-commons` previously, remove that old skill to avoid duplicates. Existing reasoning files and saved history remain compatible.
