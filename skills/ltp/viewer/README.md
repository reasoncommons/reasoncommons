# Viewer

A generated copy of the renderer in `apps/reasoning-demo/` of the Reason Commons repository, so that an installed skill can show a commons in the browser with `scripts/open_commons.py`. Do not edit these files here: change the originals and run `python3 scripts/export-skill-viewer.py` from the repository root. `--check` fails when the copy has drifted.

The fonts are Alegreya Sans, under the SIL Open Font License in `fonts/OFL.txt`.
