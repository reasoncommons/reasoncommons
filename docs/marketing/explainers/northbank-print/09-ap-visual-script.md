# Visual script: the complete AP walkthrough

Proposal: `northbank-ap-complete` revision 1. The author completed the separate script, adversarial critique and revised narrative before this visual pass. The narrative below is preserved verbatim from `08-ap-script-v2.md`; each paragraph receives one independently interpretable view. This is an editorial and source review by the author, not Stephen’s endorsement or a reader-comprehension result.

The continuous visual world remains the print business, its order ticket and the maintained paper record. Use warm paper, dark ink and terracotta for the issue being examined. Give each view a date, a short headline, one focused drawing and unchanged narration. Phones lead with the drawing after the headline, followed by supporting prose. Draw formal reasoning as proposed fragments, retaining every selected joint source. AP assessments and matrix responses are authored fictional working records, not newly endorsed LTP statements.

Add a quiet five-stage AP orientation strip. Repeat explicitly returns to Assess, Analyze and Adjust; the group closes active AP only when the agreed criteria are met. The subsequent monitoring cadence is its chosen practice. Every essential explanation stays in the main scroll. The detailed twenty-four-principle record and source/version crosswalk follow the narrative and appear in the full case.

The main sequence has fifty-four views. Each contains at most forty-two narration words. No timed playback, quiz, hover-only explanation or compulsory click. The page is readable without JavaScript; the script updates orientation only.
